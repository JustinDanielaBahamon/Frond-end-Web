¿Para qué sirven los informes?

Un informe junta alertas para revisarlas o entregarlas, por ejemplo en una revisión mensual o a una entidad aliada. Puedes elegirlas una por una o usar filtros de fechas y estado; con filtros, cada descarga trae las alertas que los cumplen en ese momento. La ciudad, la usuaria y el acontecimiento describen el informe en el documento.

  1. Nuevo reporte: elige las alertas o los filtros y ponle un nombre que diga qué contiene.
  2. PDF: para leer o imprimir. Trae un resumen por estado y por forma de activación, y la lista de alertas.
  3. Excel (CSV): para filtrar, ordenar o hacer gráficas. Se abre directamente en Excel.

Los informes contienen datos personales: compártelos solo con quien deba verlos y bórralos cuando ya no se necesiten.
